# CanSNS 仕様メモ

最終更新: 2026-09-28

## 決定事項（いただいた案のとおり）

| 項目 | 内容 |
| --- | --- |
| 納品 | 6:00〜20:59。納品中は缶のラベル（商品名・気分の帯）だけ見える。中身は見えない |
| 開店 | 21:00。開店中も納品できる |
| 廃棄 | 翌6:00。自分の缶は自分の「冷蔵庫」（アーカイブ）へ |
| 開封 | 商品ボタン → 「ガコン！」→ 取り出し口をスワイプ → 缶をタップして「プシュッ！」→ 中身 |
| コイン | なし（閲覧のじゃまになるため） |
| タイトル | そのまま商品名になる |
| 開封通知 | 缶を開けられたら投稿者に通知 |
| リアクション | おかわり / つめたいね / あったかいね / 炭酸強め / ストローを差す / 返却口に手紙 |
| 投稿側の気分 | つめた〜い / あったか〜い / しゅわしゅわ から選ぶ（自販機の値段の下の帯になる） |
| 背景 | 時刻で変わる空＋8bit風の街並み（夜は星と窓明かり） |

## 会話の中で決まったこと

- **SwiftUI（iPhoneアプリ）** で作る
- **開店に必要な最低人数は 2人**（`MachineRules.minimumMembersToOpen`）
- **納品されたことは「缶が1本増える」ことだけでわかる**
  - 納品の通知は出さない
  - まだ見ていない新しい缶には「NEW」バッジが付く（タップすると消える）
  - 中身の種類（写真・動画・音声など）は開けるまでわからない（ラベルに種類のアイコンも出さない）

## 検討事項 → 今回こう決めました（あとで変更OK）

| 検討事項 | 今回の決定 | 理由 |
| --- | --- | --- |
| 投稿の種類 | 写真1枚 / 動画15秒 / ひとこと80文字 / 音声15秒。写真・動画・音声には40文字のひとことを添えられる | 「今日」を気軽に1本にまとめられる量にした |
| 1日の投稿数 | 1人1日1本 | 「満タン」演出が分かりやすく、1本の価値が上がる |
| ラベル | 色＝気分、柄＝テンプレート4種（無地・ストライプ・ドット・ウェーブ）、中央に商品名と投稿者の絵文字 | 写真をラベルにすると開ける前に中身がわかってしまうため |
| 成分表示 | 開けたあとの画面に「成分表示」として投稿情報を表示（名称・原材料名・内容量・製造者・製造時刻・賞味期限・保存方法） | 自販機らしさを出しつつ、情報をまとめて見せられる |
| つめたい/あたたかいの使い方 | 投稿側の「気分の帯」に使い、リアクションにも「つめたいね」「あったかいね」を用意 | 両方の案を活かした |
| 他人の投稿を冷蔵庫に入れる | 開けた缶だけ入れられる。投稿者が納品時にオフにできる。入れられたら投稿者に必ず通知 | プライバシーへの配慮 |
| ストロー | 投稿者とその人だけが見られる1対1の返信スレッド | 「個別に返信する」の案どおり |
| 返却口に手紙 | 投稿者だけに届く40文字の一方通行メッセージ。1缶に1通 | 返信と役割を分けるため |
| 4桁ルーレット | 開封時に回る。4つそろうと「あたり！」の演出だけ（ごほうびなし、約1/10） | 楽しさは足しつつ、ギャンブル要素にはしない |
| 自販機が育つ | 累計納品数でレベルアップ（5, 15, 30, 60…本）。看板のライトが増える | 継続のモチベーション |
| 限定演出 | 全員納品→「満タン」/ 全員が友達の缶を開封→「全員購入済み」/ 7日連続納品→「限定ネオン」/ 新メンバー参加日→「新商品入荷」 | 条件達成型（運まかせではない） |
| 公開範囲 | 自販機（グループ）は招待コード制のみ。公開設定はまだ作らない | 親しい友達向けが中心のため |
| 人数 | 2〜8人 | 少人数がメイン。学校単位の自販機は今後の検討 |
| 外見カスタマイズ | まだ作らない | 「最初はいらない」とのことなので |
| 通知 | 開封・リアクション・ストロー・手紙・冷蔵庫・メンバー参加。毎日 19:30（納品リマインド）、21:00（開店）、5:30（廃棄前）にローカル通知 | |

## 今後の検討

- サーバー（Firebase / Supabase など）につないで、本当に友達と使えるようにする
- 学校ごとの大きな自販機、公開・鍵の切り替え
- コラボ缶・コラボデザイン、自販機の外見カスタマイズ
- アプリアイコン
